# wtdtk

A ToolKit for the Wellcome TechDev project by Maddy Parsons et al..

Includes general utilities for working with the multimodal data generated by the project.

## Python utilities

`wtdtk.names` contains implementations for parsing and serialising sample names.

## CLI tools

### `validate_sections`

Validate CSV files with information about sections.

## Contributing

[Install `uv`](https://docs.astral.sh/uv/getting-started/installation/) for managing python environments and dependencies.
Run `uv sync` to install the package and development dependencies.

Use `just` to run common development tasks.

Use `prek --install` to install linters to run as pre-commit hooks.

Use numpydoc format for docstrings.
